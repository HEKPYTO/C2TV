# Adoption example

Stand-alone caller fixture for the released `HEKPYTO/C2TV@v0.1.0` action.
It does not use C2TV's own `fixtures/` tree.

- `fixtures/good/saturating_add/` — C11 harness, std-only Rust crate, `port.toml`, and a four-case corpus for saturating i32 addition.
- `fixtures/digests.toml` — lock generated by `c2tv lock --fixtures examples/adoption/fixtures`.
- `../../.github/workflows/adoption.yml` — workflow calling the released tag action.

Each corpus case is two little-endian i32 operands. The harness returns the
saturating sum as a sign-extended 64-bit value in the v1 response frame.

From this checkout:

```sh
cargo run --offline -- check --fixture examples/adoption/fixtures/good/saturating_add --json
cargo run --offline -- self-test --fixtures examples/adoption/fixtures
```
